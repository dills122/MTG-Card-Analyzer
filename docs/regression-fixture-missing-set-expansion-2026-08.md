# Regression missing-set expansion — August 2026

This campaign adds one clean-scan end-to-end fixture from 16 previously unrepresented sets. The
baseline contained 158 enabled cases from 90 sets; the expanded corpus contains 174 enabled cases
from 106 sets.

## Selection policy

- Target sets with a distinct frame generation, unusual treatment, mechanically important layout,
  or repeated-name print-discrimination risk.
- Import one English paper print per set with the Scryfall fixture importer, seed `20260814`, and a
  one-page request bound.
- Keep the expected card name, set code, collector number, metadata, and normal blocking thresholds
  generated by the importer.
- Visually verify every downloaded scan and its Scryfall identity before enabling it.
- Run the cohort with cold OCR, image-hash, and application state before running the full corpus.

Single-set imports were used because the balanced selector optimizes aggregate category coverage;
it does not guarantee that a multi-set request returns one print from every requested set.

## Targeted results

All 16 fixtures passed as blocking cases, and all 16 exact prints were verified by their set and
collector number. The targeted run used three cold-cache shards and completed in 35.75 seconds of
wall time.

Three cases are especially useful guardrails:

- Unlimited `Scavenging Ghoul` OCR read `SCAVENGING GHONL`; fuzzy matching recovered the name at
  93.75%.
- Alliances `Royal Herbalist` OCR read `LOYAL DERBLISE`; its 73.33% name score is close to the 70%
  minimum and protects the current vintage-frame fallback behavior.
- The Dark `Sorrow's Path` needed the deeper candidate path after the initially reported title OCR
  was unusable. It still produced one exact name and print match, but took 22.17 seconds, making it
  a useful fallback-runtime boundary case.

The `NPH` Forest also verifies exact-print selection for a name shared by many catalog entries, and
the `UNF` Attraction and `ONE` showcase cases protect nonstandard modern title treatments.

## Full-corpus verification

The complete 174-case cold-cache gate passed 172 cases overall and all 167 blocking cases. The only
failures were the pre-existing non-blocking Mirage `Island` and `Illumination` fixtures. All 16 new
cases passed in the expanded catalog, so the added names and print references introduced no new
candidate ambiguity.
